# UrbanGrid AI

UrbanGrid AI is an AI-powered adaptive traffic signal optimization platform that analyzes traffic video feeds in real time and dynamically controls traffic signals to reduce congestion and improve emergency response times.

## Features

* Real-time vehicle detection
* Vehicle counting and tracking
* Lane-wise traffic density analysis
* Adaptive signal timing
* Traffic prediction
* Emergency vehicle prioritization
* Centralized monitoring dashboard

## Tech Stack

* Python
* OpenCV
* YOLOv8
* TensorFlow / PyTorch
* Flask / FastAPI
* React
* PostgreSQL
* SUMO Traffic Simulator
